# សៀវភៅពិន្ទុសិស្ស — ការដំឡើងលើ Hosting ផ្ទាល់ខ្លួន

កម្មវិធីគ្រប់គ្រងពិន្ទុសិស្ស (មត្តេយ្យ និងបឋមសិក្សា) ដែលគ្រូច្រើននាក់អាចចូលប្រើព្រមគ្នា តាមរយៈ browser។

## ឯកសារក្នុងកញ្ចប់

| ឯកសារ | តួនាទី |
|---|---|
| `index.html` | ទំព័រកម្មវិធីទាំងមូល (បញ្ចូលពិន្ទុ បញ្ជីសិស្ស ព្រឹត្តិបត្រ តារាងកិត្តិយស ការកំណត់) |
| `api.php` | ម៉ាស៊ីនមេ៖ រក្សាទុកទិន្នន័យ និងគណនីគ្រូ ក្នុង SQLite |
| `.htaccess` | ការពារឯកសារទិន្នន័យ (សម្រាប់ Apache / cPanel) |
| `templates/` | គំរូ Excel សម្រាប់គ្រូបំពេញ (មត្តេយ្យ និងបឋមសិក្សា) |

## តម្រូវការ

- Hosting ដែលមាន **PHP 7.4 ឬថ្មីជាងនេះ** និង extension **pdo_sqlite** (Shared hosting/cPanel ភាគច្រើនមានស្រាប់)។
- មិនត្រូវការ MySQL ទេ។ មូលដ្ឋានទិន្នន័យបង្កើតដោយខ្លួនឯងពេលប្រើលើកដំបូង។
- គួរប្រើ **HTTPS** (SSL ឥតគិតថ្លៃ Let's Encrypt មានក្នុង cPanel ភាគច្រើន) ដើម្បីការពារពាក្យសម្ងាត់។

## ជំហានដំឡើង (cPanel / Shared hosting)

1. ចូល cPanel → **File Manager** → ថត `public_html` (ឬបង្កើតថតរង ដូចជា `public_html/grades`)។
2. Upload ឯកសារ `index.html`, `api.php`, `.htaccess` (បើក "Show Hidden Files" ដើម្បីឃើញ `.htaccess`)។
3. បើក `https://ឈ្មោះដែនរបស់អ្នក/` (ឬ `/grades/`) ក្នុង browser។
4. លើកដំបូង កម្មវិធីនឹងសួរឱ្យ **បង្កើតគណនីអ្នកគ្រប់គ្រង** (នាយក)។ ចងចាំឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់នេះ។
5. ចូលផ្ទាំង **«ថ្នាក់ និងមុខវិជ្ជា»**៖
   - កែព័ត៌មានសាលា បង្កើតថ្នាក់ និងជ្រើសកម្រិត (មត្តេយ្យ ឬបឋមសិក្សា)។
   - នៅផ្នែក **«គណនីគ្រូ»** បង្កើតគណនីឱ្យគ្រូម្នាក់ៗ (ឈ្មោះអ្នកប្រើជាអក្សរឡាតាំង ឧ. `teacher1`)។
6. ផ្ញើតំណភ្ជាប់ ឈ្មោះអ្នកប្រើ និងពាក្យសម្ងាត់ ទៅគ្រូម្នាក់ៗ។

## សិទ្ធិអ្នកប្រើ

| | គ្រូ | អ្នកគ្រប់គ្រង |
|---|---|---|
| បញ្ចូល/កែពិន្ទុ | ✓ | ✓ |
| កែបញ្ជីសិស្ស ដាក់រូបថតសិស្ស | ✓ | ✓ |
| ចេញព្រឹត្តិបត្រ តារាងកិត្តិយស Excel | ✓ | ✓ |
| បង្កើត/លុបថ្នាក់ កែមុខវិជ្ជា ព័ត៌មានសាលា ឡូហ្គោ | | ✓ |
| បង្កើត/លុបគណនីគ្រូ ប្ដូរពាក្យសម្ងាត់ | | ✓ |

គ្រូអាចមើល និងកែពិន្ទុគ្រប់ថ្នាក់។ ទិន្នន័យដែលគ្រូម្នាក់បញ្ចូល អ្នកផ្សេងឃើញក្នុងរយៈពេលប្រហែល ១០ វិនាទី។

## ទិន្នន័យរក្សាទុកនៅឯណា?

- `api.php` ព្យាយាមដាក់មូលដ្ឋានទិន្នន័យ **នៅក្រៅថតសាធារណៈ** គឺថត `gradebook-data/` នៅជាប់ `public_html` ដែលមនុស្សខាងក្រៅមិនអាចទាញយកបាន។
- បើ hosting មិនអនុញ្ញាត វានឹងប្រើថត `data/` ជាប់ `api.php` ដែលការពារដោយ `.htaccess`។
- **បម្រុងទុក (Backup)៖** ទាញយកឯកសារ `gradebook.sqlite` ពីថតនោះ ជាប្រចាំ (ឧ. ចុងខែនីមួយៗ)។ cPanel → Backup ក៏ចម្លងវាដែរ។

## ប្រសិនបើប្រើ VPS ជាមួយ Nginx

`.htaccess` មិនដំណើរការលើ Nginx ទេ។ សូមបន្ថែមក្នុង server block៖

```nginx
location ~ /(data|gradebook-data)/ { deny all; }
location ~ \.(sqlite|sqlite-wal|sqlite-shm)$ { deny all; }
location ~ \.php$ { include fastcgi_params; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; fastcgi_pass unix:/run/php/php-fpm.sock; }
```

ឬកំណត់ថតទិន្នន័យដោយខ្លួនឯង តាមរយៈ environment variable `GRADEBOOK_DATA_DIR=/var/lib/gradebook` (ថតនោះត្រូវឱ្យ PHP សរសេរបាន)។

## សាកល្បងលើកុំព្យូទ័រ (មិនបាច់ hosting)

```bash
php -S 127.0.0.1:8000
```
រួចបើក `http://127.0.0.1:8000`។

## បញ្ហាដែលអាចជួប

- **«មិនអាចភ្ជាប់ទៅ api.php បានទេ»** — hosting មិនដំណើរការ PHP ឬ `api.php` មិនស្ថិតក្នុងថតជាមួយ `index.html`។
- **«មូលដ្ឋានទិន្នន័យមិនដំណើរការ»** — សូមបើក extension `pdo_sqlite` (cPanel → Select PHP Version → Extensions)។
- **ភ្លេចពាក្យសម្ងាត់គ្រូ** — អ្នកគ្រប់គ្រងបញ្ចូលឈ្មោះអ្នកប្រើដដែល ជាមួយពាក្យសម្ងាត់ថ្មី នៅផ្ទាំង «គណនីគ្រូ»។
- **ភ្លេចពាក្យសម្ងាត់អ្នកគ្រប់គ្រងតែម្នាក់** — លុបឯកសារ `gradebook.sqlite` នឹងបាត់ទិន្នន័យទាំងអស់។ ដូច្នេះគួរបង្កើតអ្នកគ្រប់គ្រងពីរនាក់។

កម្មវិធីប្រើ Google Fonts និងបណ្ណាល័យពី cdnjs (SheetJS, html2canvas, jsPDF) ដូច្នេះ browser ត្រូវភ្ជាប់អ៊ីនធឺណិត។
